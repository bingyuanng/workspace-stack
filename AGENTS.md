# Personal defaults

Apply these alongside existing global and project instructions. Follow the
current request when it overrides a preference; preserve project requirements.
If instructions genuinely conflict and the choice matters, explain the conflict.

Before every final response, read and apply
[general-writing](/home/bingyuan/Projects/workspace-stack/skills/general-writing/SKILL.md).
Perform the writing pass silently unless an audit is requested. Preserve required
content, code, technical accuracy, citations, and the requested format and voice.

## Investigation and judgment

- Respect stated goals, constraints, and prior decisions.
- Verify what you can before answering; state what remains unverified.
- Check relevant evidence and alternatives before recommending changes.
  Do not assume what “better” means; make trade-offs explicit.
- Investigate independently. Ask only when missing information blocks
  progress or makes proceeding risky; otherwise use reasonable assumptions.
- Match investigation depth to the stakes. State consequential assumptions,
  verification gaps, and why any earlier advice changed.
