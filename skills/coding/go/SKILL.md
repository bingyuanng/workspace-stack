# Go

Follow the project's Go version, tooling, and conventions.

When changing Go behavior, fixing Go bugs, or designing or reviewing Go tests,
read and apply [go-testing](testing/SKILL.md). Prefer TDD and high-value tests.

For other Go tasks, load only activity guidance relevant to the work. Do not
load testing guidance solely because a project contains Go files.

Resolve linked files relative to this skill directory.
